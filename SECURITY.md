# Security and privacy

Report a vulnerability through the repository's Security tab if private reporting is available. Otherwise open an issue titled “Private security contact requested” without technical details or private material. The maintainer will arrange a private channel. Only the current 0.1.x line receives fixes. Initial response target is seven days; this is a volunteer project.

Run the CLI as an ordinary local user in a directory you control. It opens the two named files and writes one new local ZIP. It makes no network calls, invokes no subprocesses, reads no media, and never executes caption markup. The HTML and JSON contain timing and numeric identifiers. The SRT contains dialogue; share it only with intended recipients. The optional include-partial mode can carry words removed from the edit. Intact cues may still contain sensitive text or markup from the original. This tool cannot certify redaction or publication safety.

Each input is limited to 8 MiB and 50,000 records. The parser rejects unsupported encodings and ASCII controls other than whitespace used by the format. ZIP member names are constant. Publishing uses a private temporary file and a no-replace filesystem operation. Use a local filesystem that supports hard links on POSIX. Sudden termination can leave a hidden staging file in the output directory. The CLI assumes a trusted local filesystem and directory owner; for shared intake, isolate the process and apply filesystem, memory and CPU limits.

The CI token has read-only contents access. Actions are pinned to commits. The optional Docker image gets its OS and interpreter from the upstream Python image. Rebuild and scan that image before distributing a production image. The repository does not operate an upload service.
